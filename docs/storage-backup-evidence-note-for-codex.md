## Honest limits

1. S3 expiry is a plain 30-day timer. If backups failed for 30 days **and** every alert were ignored, the S3 copies would age out while the local last-good snapshot stays. The 26-hour alert is the control for that.
2. The scheduler still depends on the workstation being on, and today on the Claude desktop task rather than Task Scheduler. The monitor catches a missed day either way.
3. My age implementation is pure Node and was not cross-checked against the reference `age` binary (not installed). Round trips, tamper and wrong-key refusal, bech32 vectors and a real restore of production data are tested; interop is not.
